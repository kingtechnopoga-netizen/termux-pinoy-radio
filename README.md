# VECTOR Pinoy Radio (Termux)

Pinoy FM radio player para sa Termux. May pangalan ang mga station, madaling magpalit ng channel.

## Install

```bash
pkg install python mpv -y
pip install rich
curl -LO https://raw.githubusercontent.com/kingtechnopoga-netizen/termux-pinoy-radio/main/radio.py
```

## Run

```bash
python radio.py
```

## Gamit

- Piliin ang number ng station sa menu.
- Habang tumutugtog: `q` = stop at balik sa menu, `9`/`0` = volume, `m` = mute, `space` = pause.
- `c` = mag-enter ng custom stream URL.
- `0` = exit.
